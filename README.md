# InnoFab-AkaziConnect

This is a Next.js starter project for InnoFab-AkaziConnect — a job marketplace for Rwanda.

## Quickstart

1. Copy `.env.local` and fill required variables.
2. Install deps: `npm install`
3. Run dev: `npm run dev` (open http://localhost:3000)

## Seed admin
Set ADMIN_EMAIL and ADMIN_PASSWORD in your .env.local then run:
```
node scripts/seedAdmin.js
```

## Deploy
Push to GitHub and import to Vercel. Add environment variables in Vercel dashboard.
